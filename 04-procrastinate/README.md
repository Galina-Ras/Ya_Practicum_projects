# Procrastinate Pro+ — почему не окупается реклама

Развлекательное приложение вкладывается в маркетинг и уходит в минус. Нужно найти причину по данным с 1 мая по 27 октября 2019.

## Данные

- `visits_info_short.csv` — сессии
- `orders_info_short.csv` — покупки
- `costs_info_short.csv` — рекламные расходы

## Методы

Профили пользователей, конверсия, удержание, LTV, CAC, ROI — в целом и в разрезе страны / устройства / канала.

## Главные выводы

- США дают основную долю платящих (~78%), но хуже удерживаются и не окупаются: CAC там раздут.
- TipTop и FaceBoom съедают ~83% бюджета. CAC TipTop ~2.8 $ против ~1 $ у остальных.
- FaceBoom и AdNonSense — слабое удержание при дорогом трафике.
- Из устройств к концу двух недель окупается только PC.
- Органика большая, но в платящих конвертится слабо.

**Рекомендации:** сократить TipTop/FaceBoom, переложить бюджет на окупаемые каналы (в т.ч. lambdaMediaAds), усилить работу с PC и европейскими рынками.

## Запуск

```bash
jupyter notebook procrastinate_pro.ipynb
```
