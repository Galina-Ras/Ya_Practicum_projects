# GoFast — статистический анализ сервиса самокатов

Поездки и подписки в нескольких городах: понять, выгоднее ли пользователи Ultra, и ответить на вопросы маркетинга.

## Данные

`users_go.csv`, `rides_go.csv`, `subscriptions_go.csv`

## Что проверено

- EDA: города, возраст, дистанция, длительность, free vs ultra.
- Помесячная выручка.
- Гипотезы: длительность поездок, износ самоката (3130 м), выручка ultra vs free.
- Распределения: сколько промокодов рассылать, вероятность открытия push.

## Главные выводы

- Free чуть больше, чем Ultra (54% vs 46%), медианный возраст — 25 лет.
- Пользователи с подпиской ездят дольше; помесячная выручка с Ultra статистически выше.
- Средняя дистанция Ultra не выглядит выше оптимальных 3130 м.
- Чтобы с вероятностью ~95% получить не меньше 100 продлений при p=0.1, нужно около 1161 промокода.

## Запуск

```bash
jupyter notebook gofast_stats.ipynb
```
