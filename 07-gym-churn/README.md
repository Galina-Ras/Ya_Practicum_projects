# Прогноз оттока клиентов фитнес-клуба

Сеть «Культурист-датасаентист»: кто уходит в следующем месяце и какие сегменты держать отдельно.

## Данные

`gym_churn.csv` — 4000 клиентов, факт оттока и признаки за предыдущий месяц.

## Модели

- Логистическая регрессия vs случайный лес (train/test split).
- Иерархическая кластеризация + K-Means (5 кластеров).

## Главные выводы

- Логрег чуть сильнее леса: accuracy 0.92 vs 0.91, выше precision и recall.
- Удерживают: близость к клубу, корпоративный договор, длинный контракт, групповые занятия, частота визитов.
- Кластеры 0 и 4 — лояльные (отток 3–7%); кластер 3 — зона риска (~51% оттока).

**Рекомендации:** продлевать контракты лояльным, возвращать «спящих» с низкой частотой, точечные офферы для кластера 3.

## Запуск

```bash
jupyter notebook gym_churn.ipynb
```
