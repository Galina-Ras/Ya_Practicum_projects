# E-commerce: профили потребления «Пока все ещё тут»

Интернет-магазин товаров для дома: ассортимент и сегменты покупателей для рассылок.

## Данные

`ecom_dataset_upd.csv` — заказы с октября 2018 по январь 2020.

## Что в тетрадке

1. Предобработка: неявные дубликаты (~31% строк), категории товаров, сезоны.
2. EDA: выбросы, сезонность, топ товаров, retention.
3. **RFM-сегментация** — основной результат для маркетинга.
4. Дополнительно: K-Means как альтернативный взгляд.
5. Гипотезы: различия выручки и частоты между сегментами (Манн–Уитни + поправка на множественные сравнения).

## Главные выводы

- Большинство клиентов делают один заказ (~64%); повторных мало.
- Пики: зима и весна; лето слабее. Весной/зимой чаще растения, летом/осенью — дом и быт.
- RFM даёт рабочие сегменты: лучшие клиенты, новички, уходящие ценные, низкоценные и т.д.
- Для рассылок лучше RFM: сегменты названы языком бизнеса.
