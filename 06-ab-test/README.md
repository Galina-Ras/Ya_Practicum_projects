# Приоритизация гипотез и A/B-тест интернет-магазина

Список гипотез для роста выручки: ICE/RICE, затем разбор уже проведённого A/B-теста.

## Данные

`hypothesis.csv`, `orders.csv`, `visitors.csv`

## Главные выводы

- По ICE лидирует скидка в день рождения; по RICE — форма подписки на всех страницах (большой Reach).
- Кумулятивная выручка и конверсия группы B выше; в среднем чеке B виден скачок из‑за дорогих заказов.
- По сырым и очищенным данным число заказов на посетителя в B значимо выше (p ≈ 0.02, uplift ~14%).
- Средний чек статистически не отличается; после очистки относительный разрыв почти исчезает.

**Решение:** остановить тест, зафиксировать победу B по конверсии. На средний чек тест не повлиял.

jupyter notebook ab_test.ipynb
