# Стримчик — закономерности успешных игр

Интернет-магазин игр: что ставить в кампанию на 2017 год по данным до 2016 включительно.

## Данные

`games.csv` — продажи NA/EU/JP, оценки, жанр, платформа, рейтинг ESRB.

## Главные выводы

- Актуальный срез: 2013–2016. В лидерах PS4 и XOne, рынок в целом снижался.
- По медиане продаж самый прибыльный жанр — Shooter, не Action (Action побеждает только по сумме).
- NA/EU: экшен и шутеры, рейтинг M. Япония: Nintendo 3DS и RPG, ESRB слабо применим.
- Оценки критиков слабо связаны с продажами; оценки игроков — почти нет.
- Средние пользовательские рейтинги Xbox One и PC не различаются; Action и Sports — различаются.
